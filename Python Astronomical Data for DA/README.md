# Python Astronomical Data: Stellar Data Analysis & Celestial Image Processing

This repository represents a deep dive into **Astronomical Data Analysis**, covering the full pipeline from tabular stellar classification to advanced FITS image processing and feature enhancement using `Astroquery`.

##  PROJECT OVERVIEW
As a newcomer to the IT field, this project served as a rigorous introduction to handling complex scientific datasets. The transition from standard data to astronomical imaging required a "meticulous" approach to refactoring legacy code and adapting to unique data structures.

### KEY LEARNING MILESTONES:
* **Visualizing the Invisible:** Moving beyond standard 0-255 pixel scales to handle High Dynamic Range (HDR) astronomical flux.
* **Meticulous Refactoring:** Independently sourcing datasets from Kaggle and NASA's SkyView, then manually re-mapping labels.

## 🛠️ TECHNICAL STACK
* **Astronomy:** `Astropy`, `Astroquery`
* **Data Handling:** `NumPy`, `Pandas`
* **Visualization:** `Matplotlib`, `Seaborn`

## 📊 CORE FEATURES
* **Tabular Analysis:** Created HR Diagrams and used Boxplots for outlier detection in stellar populations.
* **Virtual Telescopy:** Programmatic retrieval of **Andromeda Galaxy (M31)** data via NASA's SkyView.
* **Image Processing:** Implemented MinMax Scaling, Log Normalization, and Denoising to enhance celestial features.
