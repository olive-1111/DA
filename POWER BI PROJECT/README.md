# Learn Power BI in Under 3 Hours: Formatting, Visualizations, Dashboards

This folder documents my introduction to Power BI, focusing on the end-to-end process of transforming raw datasets into actionable business insights. As a newcomer to the tool, this project served as a deep dive into data connectivity and interactive reporting.

## WHAT I LEARNT

* **Environment Setup:** Navigating the Power BI UI and performing initial data walkthroughs.
* **Power Query:** Learning to clean and transform data before loading it into the model.
* **Data Modeling:** Establishing Joins and Relationships between different tables to create a unified data source.
* **DAX Expressions:** Writing basic Data Analysis Expressions (DAX) to create custom calculations and measures.
* **Advanced Interactivity:** Implementing Drill Downs and Groups to allow users to explore data at different levels of detail.
* **Insight Creation:** Combining data from different columns and tables to reveal hidden trends and business insights.
* **Visualization Mastery:** Exploring the creative side of data by building polished, interactive dashboards.

## OBSERVATIONS & DISCREPANCIES

* **Data Polish:** Noticed that the tutorial dataset appeared more "polished" in the video than the version provided for download, requiring additional manual adjustments.
* **Instructional Gaps:** Identified areas where specific formatting or UI steps were not shown in detail, requiring independent problem-solving.

## CHALLENGES

* **Tool Adaptation:** As a new user in IT, mastering the specific logic of Power BI's interface and the "flow" of data from Query to Report was a significant learning curve.
* **Meticulous Alignment:** Ensuring that relationships between tables were accurate was essential; even a small error in the data model would break the entire visualization.
* **Feature Discovery:** Finding the correct menus for conditional formatting and advanced chart settings often required searching beyond the tutorial.

## SOLUTIONS

* **AI-Assisted Troubleshooting:** Used AI to fill in the "skipped" steps from the tutorial, specifically for fine-tuning visualizations and fixing data model errors.
* **Meticulous Data Checking:** Developed a habit of double-checking column connections and data types to ensure the "connected" insights were accurate.
* **Independent Exploration:** Spent extra time exploring the visualization pane to discover how to make the final dashboard more interactive and "alive" than the basic tutorial version.
