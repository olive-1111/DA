# Tableau Basics: Comprehensive Full Course (6+ Hours)
> **Level:** Beginner to Expert  
> **Project Scope:** Full-scale data storytelling, advanced calculations, and dynamic mapping.

This repository documents an intensive 6-hour certification journey through Tableau. It tracks my progression from basic data connections to expert-level dashboarding, sheet swapping, and advanced geospatial mapping.

## COURSE STRUCTURE & MILESTONES

### **Level 1: Foundations & Beginner Basics**
* **Data Connectivity:** First-time experience connecting to **Microsoft Access (Northwind)** and Excel (Superstore) databases.
* **The Tableau Paradigm:** Mastering Extracts vs. Live Connections, Joins, Blends, and Metadata management.
* **Dashboard Foundations:** Building initial visual structures and filtering logic.

### **Level 2: Intermediate Analytics**
* **Multidimensional Analysis:** Comparing values across dimensions and visualizing distributions/multiple axes.
* **Calculations & Parameters:** Mastering the three levels of calculation, KPI creation, and Ad-hoc analysis.
* **Table Calculations:** Advanced partitioning, addressing, and scope/direction logic.

### **Level 3: Advanced Storytelling**
* **Strategic Formatting:** Understanding the "Value-Add" of professional formatting in data stories.
* **Interactive Dashboards:** Creating interactive stories using advanced triggers and dashboard objectives.
* **Predictive Analytics:** Implementing Trends, Distributions, and Forecasting.

### **Level 4: Expert Techniques**
* **Data Structuring:** Solving complex data issues and restructuring tables for Tableau optimization.
* **Dynamic Dashboards:** Implementing Sheet Swapping and leveraging Sets for complex business questions.
* **Geospatial Expertise:** Advanced Mapping techniques and using background images for visualization.

## OBSERVATIONS & EXPERIENCES

* **Environmental Differences:** Despite using the provided datasets, I encountered persistent differences in UI layout and numerical outputs compared to the tutorial, requiring independent tool adaptation.
* **The "Live Map" Discovery:** Found the process of creating "live" map visualizations with natural elements fascinating and a highlight of the creative process.

## CHALLENGES

* **Geospatial Hurdle:** Map visualization presented a significant technical challenge; I spent extensive time troubleshooting the logic independently when external AI tools could not provide a solution.
* **Legacy Data Access:** Connecting to Microsoft Access for the first time required navigating new interface steps not common in modern spreadsheet tools.
* **Instructional Gaps:** Managed several "skipped steps" in the tutorial by manually exploring the UI to locate specific buttons and tools.
* **Label Logic:** Creating new labels via custom calculations for X and Y axes was a complex manual process that required extreme precision.

## SOLUTIONS

* **Independent Problem Solving:** Successfully self-taught the mapping logic through trial and error when tutorial and AI guidance were insufficient.
* **Manual Adaptation:** When the "root cause" of graphical differences remained hidden, I prioritized **finishing the workflow** to ensure I mastered the tool's end-to-end functionality.
* **Creative Customization:** Combined different visualization styles and labels to ensure the "visual board" was accurate and professional, even when the tutorial skipped the setup steps.
