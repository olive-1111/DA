# Learn SQL Beginner to Advanced: MySQL Mastery & Projects

This folder documents my journey through the core language of data. Starting from a position of total unfamiliarity, I navigated the complexities of database installation, complex querying, and full-scale data cleaning using MySQL.

## WHAT I LEARNT
* **Database Architecture:** Installing MySQL and establishing a local database environment.
* **Core Querying:** Mastering SELECT, JOINs, Subqueries, and Window Functions.
* **Database Programming:** Building CTEs, Stored Procedures, and Triggers.
* **Full Projects:** Executing a Data Cleaning and Exploratory Data Analysis (EDA) project.

## OBSERVATIONS & DISCREPANCIES
* **Version Variance:** Encountered differences between the tutorial environment and my local setup, requiring constant adjustment of commands.
* **EDA Complexities:** During the final Exploratory Data Analysis phase, I identified persistent errors and output differences that could not be easily resolved by following the video alone.

## CHALLENGES
* **The "EDA" Wall:** The final Exploratory Data Analysis chapter was the most challenging; despite meticulous typing and maximum effort, technical errors occurred that were difficult to trace.
* **Command Fatigue:** Managing the long duration of the tutorial while maintaining the precision required for advanced SQL syntax.

## SOLUTIONS
* **Resilience in Learning:** When the EDA results diverged or errors persisted, I prioritized the **process over the result**, continuing to type and execute every command to understand the structural logic of the project.
* **Meticulous Manual Entry:** Typed every command one-by-one to build muscle memory, ensuring a deep understanding of SQL "grammar" even when the output was inconsistent.
