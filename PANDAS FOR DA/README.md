# Learn Pandas in Under 3 Hours: Data Cleaning & Visualization

This folder documents my transition from spreadsheet-based analysis to programmatic data analysis using Python and the Pandas library. It tracks the challenges of adapting to a code-first mindset and mastering the logic of data manipulation.

## WHAT I LEARNT

* **Environment Setup:** Learning how to "summon" data by establishing correct file paths for Python to read.
* **Data Transformation:** Mastering Group By, Aggregating, and the differences between Merge, Join, and Concatenate.
* **Data Cleaning:** Identifying and handling missing or inconsistent data within a programmatic environment.
* **Exploratory Data Visualization:** Understanding the logic behind Python-based plotting and visualizations.
* **Precision Training:** Developing the meticulous attention to detail required to avoid syntax errors in long commands.

## OBSERVATIONS & DISCREPANCIES

* **Code Sensitivity:** Observed that even tiny differences in syntax or formatting (case sensitivity, brackets) result in errors.
* **Visualization Logic:** Identified that Python visualization requires a much more structured and descriptive logic compared to the drag-and-drop nature of spreadsheet charts.

## CHALLENGES

* **Hardware Limitations:** Working on an older laptop made processing larger Jupyter Notebook files (ipynb) slow, requiring patience during data execution and rendering.
* **File Pathing:** Initially struggled with the technical process of connecting the Python script to the dataset location.
* **Command Complexity:** Adapting to "super long" commands, especially during the visualization phase, was a significant hurdle.

## SOLUTIONS

* **Resource Management:** Managed hardware lag by being patient with execution times and focusing on writing clean, efficient code blocks.
* **Path Troubleshooting:** Used AI to learn the mechanics of directory paths, successfully enabling Python to read and process local files.
* **AI-Assisted Debugging:** Utilized AI as a real-time tutor to explain error messages and bridge gaps when the tutorial's logic didn't produce the expected results.
