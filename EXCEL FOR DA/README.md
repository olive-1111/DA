# Excel Data Analysis Project

This folder contains the datasets and workbooks from a 7+ hour Data Analysis course. It documents my progression from basic data organization to advanced automation and Power Pivot modeling.

## WHAT I LEARNT

* Intro to Data Analysis: List Design Basics, Inserting Tables, Filtering Data, and Using the Total Row.
* Visualizations: Recommended Charts, Adjusting Charts, Sparklines, and Combo Charts.
* Logical Functions: IF Function, SUMIF, AVERAGEIF, SUMIFS, and Nesting AND with IF.
* Pivot Tables: Preparing Data, Pivot Table Components, Slicers, Timelines, and Report Filter Pages.
* Advanced Pivot Features: Calculated Fields, Pivot Table Layouts, and Designs.
* Power Pivot: Adding Tables to Data Models, Creating Table Relationships, and DAX Expressions.
* Modern Excel Features: XLOOKUP for joining datasets and handling multiple values.
* Excel Copilot: Setup, Copilot Pane, Insights, Visualizing Data, and Copilot Lab.
* Automation and Macros: Flash Fill for data mining, Developer Tab, Macro Basics, Relative Reference Macros, and VBA Basics.

## OBSERVATIONS & DISCREPANCIES

* Version Differences: Noticed that certain UI elements and menu locations in my version of Excel differed from the tutorial’s interface.
* Feature Gaps: Identified that "Advanced" features shown in the video required manual activation of the Developer tab and Power Pivot add-ins which were not explained in detail.
* Data Output: Observed slight variations in final results compared to the tutorial, likely due to updates in the dataset or Excel's calculation engine over time.
* Formula Availability: Discovered that legacy versions of Excel do not support modern functions like XLOOKUP, requiring a shift in strategy to cloud-based tools.

## CHALLENGES

* Software Versioning: My local laptop did not support XLOOKUP or Copilot features.
* Learning Curve: As a newcomer to IT, the density of new features and formulas required significant adaptation.
* Tutorial Gaps: Certain parts of the tutorial moved quickly or skipped minor configuration details.

## SOLUTIONS

* Excel Cloud: Transitioned to the web-based version of Excel to access the full range of modern features and XLOOKUP.
* AI Integration: Used AI to troubleshoot specific errors and explain features that weren't shown in detail during the video.
* Manual Setup: Researched how to manually activate the Developer Tab and Power Pivot add-ins to match the instructor's setup.
